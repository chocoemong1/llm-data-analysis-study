# 프로젝트 루트 찾기 실습

[블로그 가이드](https://blog.naver.com/dev-dog/224404509476)의 순서대로 다음을 확인했습니다.

1. 현재 작업 폴더에서 상위 폴더를 탐색하는 코드
2. 시작 위치를 받을 수 있는 함수
3. `course_utils.paths` 공용 모듈
4. `pyproject.toml`과 editable 설치
5. 깊은 Notebook 폴더에서 동일한 프로젝트 루트와 `data` 경로 반환

실행 결과는 [`notebooks/ch04/project_root_practice.ipynb`](notebooks/ch04/project_root_practice.ipynb)에 저장되어 있습니다.
