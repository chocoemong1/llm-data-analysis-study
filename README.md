# LLM Data Analysis Study

「대규모언어모델(LLM)을 활용한 빅데이터분석」 수업의 개인 실습 결과를 정리하는 저장소입니다.

## 원본 수업 자료

- 공식 저장소: <https://github.com/GilbertMoon/llm-data-analysis-course>
- 원본 자료는 `../llm-data-analysis-course`에서 확인합니다.
- 공식 저장소의 원본은 수정하지 않고, 개인 답안과 Evidence만 이 저장소에 기록합니다.

## 제출 파일

- Chapter 01~02: `chapterNN/chapterNN.md`
- Chapter 03~15: `chapterNN/chapterNN.ipynb`
- Notebook 밖의 핵심 Evidence: `chapterNN/images/`

각 제출물에는 실행 내용과 결과뿐 아니라 결과 관찰, 나의 해석과 판단, 업무·분석적 의미, 한계와 추가 확인 사항을 함께 기록합니다.

## 기본 작업 흐름

1. 공식 저장소의 공통 제출 가이드와 해당 Chapter 가이드를 확인합니다.
2. 템플릿 또는 Notebook을 해당 Chapter 폴더에 복사합니다.
3. 실습을 수행하고 핵심 Evidence를 남깁니다.
4. 개인정보, API Key, Token, Secret이 없는지 확인합니다.
5. `git status`, `git add`, `git commit`, `git push` 순서로 반영합니다.
6. 저장소 루트가 아닌 해당 Chapter 최종 파일 URL을 제출합니다.
