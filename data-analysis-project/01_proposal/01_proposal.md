# 온라인 쇼핑몰의 상품별 거래금액 집중도와 취소 거래의 영향 분석

1차 프로젝트 기획 · chocoemong1 · 2026-09-29

## 1. 배경 및 목적

온라인 쇼핑몰의 거래금액이 일부 상품에 집중되는 정도와 월별 차이를 확인하고, 취소 거래의 반영 여부에 따라 지표가 얼마나 달라지는지 분석한다. 상품 운영 담당자가 우선 점검할 상품과 일관된 집계 기준을 정하는 데 참고할 수 있다.

## 2. 핵심 분석 질문

1. 거래금액 상위 10개 상품은 무엇이며, 전체 금액의 몇 %를 차지하는가?
2. 월별 거래금액 차이는 주문 수와 주문당 평균 금액의 차이로 어떻게 설명되는가?
3. 취소 거래를 포함하거나 제외하면 총 거래금액과 상품 순위가 얼마나 달라지는가?

## 3. 데이터 확보 계획 및 확인 결과

- **확보 방법:** 공식 페이지의 ZIP을 내려받아 `Online Retail.xlsx`를 읽는다. 별도 계정이나 API Key는 필요하지 않다.
- **실제 확보:** 2026-09-29 전체 파일 로딩 완료. **주문 상세 541,909행 × 8개 컬럼**, 약 23.7 MB이며 기간은 **2010-12-01~2011-12-09**이다. [확인 기록](../docs/data_check.json)
- **분석 범위:** 월 전체를 비교할 수 있는 **2011년 1~11월 영국 거래**로 제한한다. 전처리 전 431,427행이며, 취소 표시 행도 6,948행 있어 세 질문을 확인할 수 있다.

## 4. 데이터 구조와 질문의 연결

한 행은 주문 한 건 전체가 아니라 주문 내 상품 상세이다.

| 컬럼 | 의미와 활용 |
| --- | --- |
| `InvoiceNo`, `InvoiceDate` | 주문 식별·취소 표시와 거래 시각: 고유 주문 수, 월별 비교 |
| `StockCode`, `Description` | 상품 코드와 설명: 상품별 금액·순위 |
| `Quantity`, `UnitPrice` | 수량과 단가(GBP): `거래금액 = 수량 × 단가` |
| `CustomerID`, `Country` | 고객 식별자와 국가: 영국 범위 선택; 고객 ID는 핵심 질문에 필수 아님 |

## 5. 예상 분석 방법 및 검증

- **품질·전처리:** 결측·중복·수량·단가·날짜형을 확인한다. 원본에서 고객 ID 결측 135,080행과 완전히 동일한 중복 후보 5,268행을 확인했다. 고객 ID 결측만으로 상품·월별 집계에서 제외하지 않으며, 중복 후보는 발생 이유와 유지·제거 시 차이를 검토한다. 비상품 코드와 비정상 값은 별도 분류하고 처리 근거·행 수를 기록한다.
- **집계·시각화:** 기본 범위는 취소 표시가 없고 수량·단가가 양수인 거래로 정한다. 상품별 금액·상위 10개 비중, 월별 고유 주문 수·주문당 금액을 집계하고 막대·선 그래프로 비교한다.
- **취소 비교:** `InvoiceNo`가 `C`로 시작하는 행의 수량 부호를 확인하고, 같은 기간·국가·상품 기준에서 취소 금액을 부호대로 반영한 결과와 비교한다. 원주문과 취소의 개별 대응을 보장할 수 없어 이를 환불률로 해석하지 않는다.
- **검증·한계:** 원본 필터 합계와 그룹별 합계, `월 금액 = 고유 주문 수 × 주문당 금액`을 대조한다. 관찰과 해석을 구분하며, 오래된 단일 업체 자료를 현재 시장 전체로 일반화하거나 거래금액을 이익·회계상 순매출로 해석하지 않는다.
